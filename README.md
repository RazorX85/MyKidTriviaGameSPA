# Trivia Curiosa (deploy copy)

This repository holds the **built, public copy** of a bilingual (Spanish/English) trivia game for kids.
It is generated automatically from a private source repository; please don't edit files here by hand,
because the next deploy will overwrite them.

It is a static site: Cloudflare Pages serves it as is, with no build command and the repository root as
the output directory.
